## 1. Orientation decision (TA-01 / I01, with TC-14 / I03)

**Choice: (b) — the balanced path-tie is extended to the whole reversal-fixed set of the declared invariants.**

Proposed `[DEF]` text for §6.3 (replacing line 572; to be built in v2.12.14):

> **Path orientation rule (TDRG-ORIENT).** For a path P_n (n ≥ 3) listed as [v_1,…,v_n]: S = Σ_i signed_defect_error(θ_{v_i}, θ_{v_{i+1}}, N). Orient forward if S > 0, reversed if S < 0. If S = 0, let E = signed_centered(δ_{v_n} − δ_{v_1}, N): forward if 0 < E < N/2, reversed if −N/2 < E < 0. If S = 0 and 2E ≡ 0 (mod N), i.e. E ∈ {0, N/2}: **balanced path-tie** — the pair (S, E) is invariant under reversal of the listing there, so no orientation can be read from the declared invariants (SG-14). Policies treat the tie as before (`bound_path_tie`, `bound_symmetric`: inert bound state; `trap`, `bound_multistar`: ambiguous).

and an `[ALG]` remark beside it:

> **No-go on the declared invariants.** Reversal of the listing maps S ↦ −S always (on a defect edge |signed_defect_error| ≤ k < N/6, so the centered representative never reaches N/2), and maps E ↦ −E except when δ_{v_n} − δ_{v_1} ≡ N/2, where signed_centered returns +N/2 for both listings. Hence on S = 0 ∧ E ≡ N/2 every selector that is a function of (S, E) alone is either the tie or depends on the listing — the latter is the label fallback Appendix B rejects. **Existence of a richer covariant selector (recorded, not adopted):** for P_3 the centre-relative quantity G = sc(δ_{v_1} − δ_c) − sc(δ_{v_3} − δ_c) is reversal-odd and never 0 on the stratum (atlas C2), so a covariant non-tie rule exists if the centre token is admitted as an orientation input; for even n a palindromic configuration can still force a tie.

**Why (b) and not (a).** (1) It changes no ingredient of the law: the existing tie clause already says "no gauge-invariant orientation exists under current axiom set", and the stratum is exactly the remaining set where that sentence is true of (S, E); (b) states the clause correctly instead of adding a law. (2) (a) admits a new input (the centre token) only on a measure-small stratum, needs a second rule for n ≥ 4 and still a tie for palindromic even n; choosing it is a dynamical-law choice of the TDR-19 kind (policy selection is OPEN), not a correction, and does not belong in a corrections-only edition. (3) (b) is the `bound_symmetric` reading itself — the canonical branch binds configurations that carry no covariant choice instead of inventing tie-breakers (SG-8 unchanged). (4) (a) remains available as a named alternative policy for the later sensitivity campaign (the PI's deferred rerun), where the G-rule and the extended tie can be compared on the same universes.

**Covariance group (new guard SG-14, proposed text):**

> **SG-14 — relabelling covariance.** The TDR-G step must commute with G_cov = Sym(V) × Z_N^phase: every permutation of node labels (path-listing reversal included) and the global phase shift θ_i ↦ θ_i + c (SG-2).
