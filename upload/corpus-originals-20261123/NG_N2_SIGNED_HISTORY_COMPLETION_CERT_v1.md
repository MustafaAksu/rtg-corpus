## 1. N-1 input

Let

\[
\mathsf M_T=\{\mathrm{id},T,T^2,T^3,\ldots\}
\]

be the transformation monoid of the exact primitive dyadic generator restricted to the N-1 tube \(\mathcal U\). N-1 proves that \(\mathsf M_T\) is a free monoid on the distinguished generator \(T\). Hence:

1. every element has a unique finite word/power representation;
2. \(\mathsf M_T\) is commutative (it is monogenic);
3. \(\mathsf M_T\) is left- and right-cancellative;
4. \(T^r\neq T^s\) for distinct finite powers.

No inverse transformation \(T^{-1}\) is assumed.

## 2. Pair object and equivalence relation

Form the set of ordered pairs

\[
\mathsf M_T\times\mathsf M_T.
\]

Interpret \((A,B)\) as an **oriented comparison of two forward histories**. Define

\[
\boxed{
(A,B)\sim(C,D)
\iff
A\circ D=B\circ C.
}
\]

This definition uses only forward elements of \(\mathsf M_T\).

### Reflexivity

Because \(\mathsf M_T\) is commutative,

\[
A\circ B=B\circ A,
\]

so \((A,B)\sim(A,B)\).

### Symmetry

If \(A\circ D=B\circ C\), then \(C\circ B=D\circ A\), so \((C,D)\sim(A,B)\).

### Transitivity

Suppose

\[
(A,B)\sim(C,D),\qquad(C,D)\sim(E,F).
\]

Then

\[
A\circ D=B\circ C,
\qquad
C\circ F=D\circ E.
\]

Multiplying the first equality by \(F\) and using the second gives

\[
A\circ D\circ F
 =B\circ C\circ F
 =B\circ D\circ E.
\]

Cancellation of the common factor \(D\) yields

\[
A\circ F=B\circ E,
\]

hence \((A,B)\sim(E,F)\).

Therefore \(\sim\) is an equivalence relation.

## 3. Common-forward-extension invariance

For every \(K\in\mathsf M_T\),

\[
(A,B)\sim(A\circ K,B\circ K),
\]

because

\[
A\circ(B\circ K)=B\circ(A\circ K).
\]

Thus a signed-history class is unchanged when the same forward relational continuation is appended to both sides of the comparison. This is the RTG-native content of “difference is unchanged by a common continuation.”

No backward evolution is introduced.

## 4. Group law on equivalence classes

Let

\[
\mathsf G_T:=(\mathsf M_T\times\mathsf M_T)/\!\sim
\]

and write \([A,B]\) for the class of \((A,B)\).

Define

\[
\boxed{
[A,B]+[C,D]:=[A\circ C,B\circ D].
}
\]

### Well-definedness

Assume

\[
(A,B)\sim(A',B'),
\qquad
(C,D)\sim(C',D').
\]

Then

\[
A\circ B'=B\circ A',
\qquad
C\circ D'=D\circ C'.
\]

Multiplying these identities and using commutativity gives

\[
(A\circ C)\circ(B'\circ D')
=(B\circ D)\circ(A'\circ C'),
\]

so

\[
(A\circ C,B\circ D)\sim(A'\circ C',B'\circ D').
\]

Hence the operation is well-defined.

Associativity and commutativity are inherited from composition in \(\mathsf M_T\).

The identity is

\[
0_G=[\mathrm{id},\mathrm{id}].
\]

The inverse of a class is

\[
\boxed{
-[A,B]=[B,A].
}
\]

Indeed,

\[
[A,B]+[B,A]=[A\circ B,B\circ A]=[\mathrm{id},\mathrm{id}],
\]

because \((A\circ B,B\circ A)\sim(\mathrm{id},\mathrm{id})\).

Therefore \(\mathsf G_T\) is an abelian group.

## 5. Canonical embedding of forward histories

Define

\[
\iota:\mathsf M_T\longrightarrow\mathsf G_T,
\qquad
\boxed{\iota(A)=[A,\mathrm{id}].}
\]

Then

\[
\iota(A\circ B)
=[A\circ B,\mathrm{id}]
=[A,\mathrm{id}]+[B,\mathrm{id}],
\]

so \(\iota\) is a monoid homomorphism.

If \(\iota(A)=\iota(B)\), then

\[
(A,\mathrm{id})\sim(B,\mathrm{id}),
\]

which means

\[
A=B.
\]

Thus

\[
\boxed{\iota\text{ is injective}.}
\]

The unsigned N-1 history monoid therefore embeds without collapse into the signed-history group.

## 6. Infinite cyclic structure

Let

\[
g:=[T,\mathrm{id}].
\]

Every pair in \(\mathsf M_T\times\mathsf M_T\) has the form \((T^m,T^n)\) in the mathematical metalanguage, hence

\[
[T^m,T^n]=m g+n(-g).
\]

Thus \(\mathsf G_T\) is generated by \(g\).

The generator has infinite order. If a positive finite power of \(g\) were the identity, then for some nonzero finite \(k\),

\[
[T^k,\mathrm{id}]=[\mathrm{id},\mathrm{id}],
\]

which by the defining relation would imply

\[
T^k=\mathrm{id},
\]

contradicting N-1 orbit/power non-collapse.

Therefore \(\mathsf G_T\) is infinite cyclic.

Only now introduce the standard integer representation

\[
\Psi:\mathsf G_T\to(\mathbb Z,+),
\qquad
\boxed{
\Psi([T^m,T^n])=m-n.
}
\]

The defining pair relation is equivalent, by N-1 freeness, to

\[
m+d=n+c,
\]

so \(m-n=c-d\); hence \(\Psi\) is well-defined. The converse is immediate, and \(\Psi\) preserves addition. Therefore

\[
\boxed{
\mathsf G_T\cong(\mathbb Z,+,0).
}
\]

This is a mathematical representation of the already-constructed signed-history comparison group; \(\mathbb Z\) was not used as a primitive physical coordinate in the construction.

## 7. Non-reversal interpretation

The negative generator is

\[
-g=[\mathrm{id},T].
\]

It is obtained by reversing the **orientation of the comparison pair**, not by applying an inverse physical trajectory.

No statement of the form

\[
T^{-1}:\mathcal U\to\mathcal U
\]

is assumed or needed.

The group inverse

\[
[A,B]\mapsto[B,A]
\]

means: “compare B relative to A instead of A relative to B.”

Thus signed history represents oriented comparative excess between two forward relational histories.

## 8. Universal property

Let \(G\) be any abelian group and let

\[
f:\mathsf M_T\to G
\]

be any monoid homomorphism. Define

\[
\widetilde f([A,B])=f(A)-f(B).
\]

The pair relation ensures this is well-defined, and \(\widetilde f\) is the unique group homomorphism satisfying

\[
\widetilde f\circ\iota=f.
\]

Hence \((\mathsf G_T,\iota)\) has the Grothendieck universal property of the group completion of \(\mathsf M_T\).
