# 1. Core conclusion: one coordinate system is the wrong target

RTG should not search for a single universal coordinate system. Different layers contain different kinds of objects:

\[
\text{primitive relational content}
\rightarrow
\text{presentation / carrier realization}
\rightarrow
\text{dyadic state and comparison}
\rightarrow
\text{multi-dyad incidence / shared genesis}
\rightarrow
\text{cycle and history structure}
\rightarrow
\text{effective linear / tensor / geometric structures}.
\]

The correct target is a **representation discipline** rather than a universal coordinate chart.

## 1.1 Proposed terminology

### RRF — Relational Representation Framework

**[HYP] Proposed definition.** RRF is the project-level framework specifying:

- what the state object is;
- which relations and constraints are primitive or derived;
- which carrier/algebra represents them;
- which coordinate chart or basis is being used;
- which gauge/relabeling transformations are admissible;

- how one representation is transported to another;
- how birth/genesis events transport, erase, or create information.

**[HYP] Proposed definition.** PRR is the minimum pre-spatial layer of RRF. It must not assume, unless separately earned:

- a vector space;
- a tensor space;
- a manifold;
- a metric;
- a spatial origin;
- a scalar field;

- a particular dimensionality.

The intended question is not “which primordial tensor?” but:

\[
\boxed{\text{What is the minimum relational structure from which useful representations can be earned?}}

**Current registration:** the proposed profile mechanism is now instantiated by Registry v0.6 [S02]; this does not make the registry adopted or assign a numerical/geometric carrier to PRR0–5. The ladder is a dependency/interpretation guide, not a claimed chronology of the universe.

# 2. Foundational principle: relational, not positional

The working principle is:

\[
\boxed{\text{Physical content is relational rather than positional.}}
\]

This does **not** imply that the mathematics may never contain a zero, identity, or chosen reference.

The crucial distinctions are:

\[
\boxed{
\text{coordinate/presentation origin}
\neq
\text{composition unit}
\neq
\text{operational zero-distinction}.
}
\]

## 2.1 Origin choice versus physical origin

A coordinate origin can be introduced to represent a relational state without being physically primitive. This is familiar in affine/torsor mathematics: a reference can coordinatize an origin-free carrier.

**[SOURCE]** The relational ontology note already formulates the carrier-specific torsor idea and explicitly warns that using the torsor action as physical origin-freedom requires covariance of the actual dynamics. Algebraic torsoriality and physical admissibility remain different conditions.

## 2.2 Composition identity is not yet zero distinction

A category/groupoid-like identity

\[
1_A:A\to A
\]

is only a composition unit. It should not automatically be interpreted as a physical “zero distinction.”

A physically substantive zero-distinction claim is instead of the form

\[
A\neq B,
\qquad
A\sim_{\rm op} B,
\]

where distinct presentations are operationally indistinguishable under declared continuations and observables.

**Revision to the early PRR ladder:** composition identity and operational zero-distinction belong to different layers.

**Source scope:** the carrier-specific distinction comes from the noncanonical relational ontology note [S07, §§1–4]; the adopted OFN scope and rank-typing requirements are retained as contextual commitments [S09]. This synthesis does not identify a composition unit with an operational zero-distinction state.

# 3. Minimum structure: go below vector and tensor space

The discussion initially considered torsors, vector spaces, and tensor spaces. The refined conclusion is that even these may be too structured for the first layer.

## 3.1 Minimal candidate

At the lowest scientific representation level, use:

- distinguishable presentations/roles only when needed;
- typed relations;
- partial composition only where physically admissible.

A generic relation may be written

\[
r:A\to B.
\]

Composition is not assumed total:

\[
\star:\mathcal D\subseteq \mathrm{Rel}\times\mathrm{Rel}\to\mathrm{Rel}.
\]

Associativity is not silently assumed across event/birth sector changes. It must be separately established where relevant.

## 3.2 Category/groupoid/torsor are earned structures

A category-like realization requires units and associativity. A groupoid additionally requires inverses. An algebraic torsor requires a free and transitive group action. Treating that action as a physical gauge additionally requires compatibility with the actual state, event, continuation and observable rules; this is not part of the bare mathematical torsor definition.

Therefore:

\[
\boxed{
\text{typed relation system}
\rightarrow
\text{category/groupoid/torsor only if earned}.
}
\]

This avoids turning a convenient mathematical completion into an ontological axiom.

## 3.3 Vector/module/tensor layers come later

A vector-space claim requires an additive law and scalar action. A tensor construction requires an already defined module/vector structure.

Thus:

\[
\boxed{
\text{relation}
\rightarrow
\text{carrier algebra}
\rightarrow
\text{module/vector realization}
\rightarrow
\text{tensor structures}
\rightarrow
\text{geometry}.
}
\]

A complex representation does not by itself mean that the physical carrier is a complex vector space.

# 6. Reference consumption and the \(n-1\) principle

A key structural observation is that one presentation may be “spent” as reference/gauge when only relations are physical.

Suppose a group carrier \(G\) has presentations

\[
x_1,\ldots,x_n\in G
\]

and a common left action

\[
x_i\mapsto gx_i
\]

is gauge. Then the physical presentation sector is

\[
\boxed{G^n/G_{\rm diag}}.
\]

For an ordered dyad,

\[
[(x_A,x_B)]\mapsto R_{AB}=x_A^{-1}x_B
\]

is well-defined under the common left action. Gauge-fixing \(x_A=e\) is only one representative of that quotient, not the definition of the relation.

This supplies the precise version of the intuitive “one reference is consumed” rule:

\[
\boxed{n\text{ presentations}\;\Rightarrow\;n-1\text{ relative variables in the exact/reference sector}.}
\]

## 6.1 Connected systems only

The \(n-1\) count requires a connected co-realisation/reference structure. Distinct disconnected components retain independent overall reference freedoms.

## 6.2 Cycle content lies beyond the \(n-1\) exact sector

For a connected graph with \(n\) vertices, \(m\) edges and cycle rank

\[
\beta=m-n+1,
\]

the scalar-cochain exact/reference sector over a field has dimension \(n-1\), and the cycle quotient has dimension \(\beta\). This is a dimension statement, not a canonical choice of complementary subspace or a count of physical spatial axes:

\[
\boxed{m=(n-1)+\beta.}
\]

For a triad:

\[
3=2+1.
\]

This is the first clean bridge between reference-consumption and genuinely higher relational content.

**Scope:** these linear ranks require the declared graph and coefficient field; one must recompute the support graph for partial edge data. NUMGEN retains this domain guard and a separately qualified abelian-group completeness result [S04, NG-7A / §6.8]. For a group-valued quotient, “n−1 variables” means relative group elements, not automatically n−1 real dimensions or independently readable measurements.

# 22. Emergence taxonomy and the actual discriminating tests

## Type I — representational emergence

The same information has a different **invertible, domain-specified** representation. Lifted \((\rho,\eta)\leftrightarrow W\) and the certified local \(W\leftrightarrow z\) are examples. Unrestricted wrapping, projection, averaging or forgetting a lift is not covered by the claim of information preservation. [S02, transport graph]

## Type II — readability emergence

Retained relational information becomes available to the declared observable/continuation interface, possibly only at higher arity. Retention, a valid common realization and actual readability must all be identified.

## Type III — ontic/genesis emergence

A model introduces a genuinely new independent relational datum. A newly named variable, a noninjective update or lack of recovery from a coarse observable is not by itself such a theorem. Its independence is relative to the complete declared parent/birth inputs and admissible state constraints.

## 22.1 No-erasure is necessary for persistence, not an iff emergence classifier

**[SOURCE]** (Noncanonical ontology-note result.) The deterministic quotient lemma states that, once the event and all continuations descend to the chosen quotient, operational no-erasure requires injectivity of the event on that quotient. Its converse is not established: recoverability need not provide an admissible readable witness. [S07, §6]

The source reports canonical clean-star birth as recoverable on the declared event domain under global phase gauge and admissible relabeling, but not covariant under the proposed extra common-advance-shift quotient. The source statement and its scoped witness are retained; no certificate was rerun here and no new TDR-G owner adoption is asserted. [S07, §§7–7.1]

For the inheritance ledger, use **three distinct questions**:

| Test | Direction | Meaning |
|---|---|---|
| Forward dependence | Do the complete parent state and declared birth data determine the child datum? | A function/existence or factorization question; not injectivity |
| Quotient recoverability | Can the post-event physical quotient recover the pre-event quotient? | An injectivity/no-erasure question, after covariance |
| Operational readability | Can admissible continuations and observables distinguish the retained alternatives? | A measurement/history question, not implied by injectivity alone |

Only with the relevant answers can a datum be classed as retained, re-expressed, lost, or independently introduced. A deterministic many-to-one event can erase information without adding any; an injective event can append a redundant deterministic coordinate. Neither fact alone classifies Type II/III. This is an explicit clarification of v0.2's overcompressed criterion, not a new source theorem or a revision of the clean-star result.

**Working routing:** the ledger first fixes input/output variables, event domain, quotient, and retained markers. A failed noncovariant quotient tests the quotient hypothesis, not physical erasure. A child datum not recoverable from an incomplete parent summary is not automatically ontically new.
