## 2. Registry contract and guards

[DEF] Every record contains

\[
(\text{carrier},\ \text{observables},\ \text{constraints},\ \text{transformation law},\ \text{closure status},\ \text{memory}).
\]
(rep: [ABSTRACT]; requested registry schema, not a physical carrier)

The machine record also names the compared baseline, source/version/hash/locator, result scope, model clock, evidence actually checked, next test, and separate adoption state. A numerical PASS count is not a count of emergence theorems.

**Guard RER-G1 — relative information.** “New” must name the baseline readout. A signed area can be new relative to three Gram numbers while already determined by the full ordered vectors. A new formula or collective function is not automatically new independent data. A joint collection of component states may determine what no single component alone determines.

**Guard RER-G2 — static versus dynamic completeness.** Invariance and static orbit completeness do not imply that the actual dynamics descends to the invariant coordinates. Conversely, a prescribed closed diagnostic ODE is not evidence that it is a reduction of a separately specified microscopic map.

**Guard RER-G3 — model/profile/action.** Every comparison carries all three. RRF v0.7's DYAD-W→NET-W-RAW bridge remains OPEN; normalizing isolated edges does not leave network closure unchanged. Multiplicative network edges and TDR-G profiles remain unregistered. Abstract examples stay marked abstract/unregistered, not silently assigned a profile.

**Guard RER-G4 — orientation units.** Keep primitive Omega_G=(sqrt(3)/2)omega_raw separate from recovered producer Omega_T=−sqrt(3)omega_raw. For identical planar values only, B_T=2B_G gives Q_T=2Q_G, I_T=2I_G and Omega_T=−2Omega_G. No generator, event or birth-law transport follows from those metric identities.

**Guard RER-G5 — no restored diagnostics.** Adopted Triadic v1.6 governs this draft. The historical x*, safety wedge, fatal sectors and no-basin chain are not current premises. M_root is root-closed with K=1; independent-orientation K<1 models need a separately admitted carrier and rate.

**Guard RER-G6 — history and physical interpretation.** A retained phase theorem is not a one-variable network memory-closure theorem. Node identity, deterministic role generation, cycle content, product dimension, and physical spacetime dimension are separate questions. No source/adoption/consumer state changes by inclusion here.

## 5. Exact representation, closed dynamics, and memory

### 5.1 [THM] Exact deterministic quotient criterion

**Origin:** attachment §4B; the elementary proof is supplied here. **Scope:** deterministic set maps, no physical selection.

Let T:X→X on the declared invariant domain and Phi:X→Y. There exists a unique update on Phi(X) satisfying

\[
\Phi\circ T=F\circ\Phi
\]
(rep: [ABSTRACT]; deterministic common-domain reduction)

if and only if

\[
\Phi(x)=\Phi(x')\ \Longrightarrow\ \Phi(Tx)=\Phi(Tx').
\]
(rep: [ABSTRACT]; fibre-consistency test)

**Proof.** Necessity follows by applying F. Conversely define F(y)=Phi(Tx) using any x with Phi(x)=y. The condition makes the value independent of the representative. T(X)⊆X ensures the codomain. Uniqueness holds on Phi(X). □

For partial/event updates, use an invariant domain or record the event/admissibility predicate and ensure the relevant domain is determined by the reduced data. Different input/output arities require typed maps; this theorem does not identify them. Smoothness, locality, allowed computation and minimum dimension are further properties, not hidden consequences.

### 5.2 Exact static quotient is only the first test

For the primitive signed-Gram data, put Omega_G=−det(L_Es,L_Ec), where L_EᵀL_E=B_G. On Qs>0 choose the Euclidean representative

\[
s_E=(\sqrt{Q_s},0),\qquad
c_E=\left(\frac{I_{sc}}{\sqrt{Q_s}},-\frac{\Omega_G}{\sqrt{Q_s}}\right).
\]
(rep: [UNREGISTERED]; kinematic representative of the primitive B_G pair, not a physical frame choice)

The Gram constraint makes |c_E|²=Qc. Any ordered pair with the same signed readout is related to this representative by a simultaneous proper B-isometry. Thus the static fibres are known on this patch. At Qs=0 a separate chart is required; at Omega_G=0 chirality sign is not a distinct value.

This construction does not assert that the microscopic Tpost admits this common-rotation quotient. That is precisely the first triadic closure test still pending. The physical RRF pole action is not replaced by the kinematic isometry group used in this proof.

### 5.3 Memory must receive its own closure test

When Y fails, a proposed state (Y,M) must come with an actual map or source-defined evolution and satisfy the same fibre criterion. Alternatively, a history law must specify which histories are admitted and what information is retained. Neither finite memory nor sufficiency of the entire observed past is presumed.

If T and the complete x are fixed and known, values computed from x do not automatically add independent state information. Access to a counterfactual evaluation may still be operationally disallowed. A physical access restriction and an information-theoretic distinction therefore need separate entries.

R9’s source memory theorem is retained in RER-N01 with its native comparator and paired domains. Its known existence does not select M for a different triadic or network model. No registry entry presently proves minimal finite-memory closure for that enlarged setting.
