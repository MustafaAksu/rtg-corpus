# DZT recovery intake

Originals are under originals/downloads/ and originals/legacy-src/. Relative
paths, filenames (including numbered suffixes), and file bytes are preserved.
No original was executed, normalized, renamed, deduplicated, or removed.
MANIFEST.json and SHA256SUMS describe this collection. DUPLICATE_HASHES.json
reports equal hashes only; it does not select a canonical version.

This is a recovery submission, not a scientific certificate or adoption.
A current hash does not prove identity with a historical artifact unless an
independent historical hash or other adequate provenance is available.
The search does not cover other directories or names outside the stated filter.
Repository receipt should follow the upload/* intake and hash-verification
workflow before any placement or scientific use.
