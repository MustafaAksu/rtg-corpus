# DZT-REQ-003 — Certified local-germ data for the B1 weight audit

**RID:** DZT-REQ-003
**Requesting branch:** DZT (RTG_DYADIC_ARITHMETIC_RESONANCE_TRANSFORM_DSN, v0.10)
**Target branch:** Dyadic (local NF / germ machinery near $P_1$)

**Status:** OPEN (awaiting Dyadic export)

## Purpose

Open Track B1: audit candidate weights $W^{(B)}$, $W^{(C)}$ for a **formal local zeta**
$$\zeta_{\rm loc}(z)=\exp\!\Big(\textstyle\sum_{m\ge1} W_m z^m/m\Big)$$
near the order-6 elliptic point $P_1$ ($G=T^6$). DZT cannot audit these without certified local
germ data: the linearization is degenerate (see below), so the weights must be built from
**subleading/nonlinear** local coefficients — which are gauge-dependent and therefore must be
exported under a declared convention with their transformation law.

## Why a stamped export is required (not ad-hoc coefficient borrowing)

- **$W^{(A)}$ is already rejected (DZT-verified, v0.10).** At the exact order-6 point $G=T^6$ has
  linearization eigenvalues $\mu^6=1$, so $\det(I-DG^m)=0$ for all $m$ ($1/\det$ weight diverges)
  and $\mathrm{trace}(DG^m)=2$ is constant (lookup table). The linear spectrum carries no local
  information.
- **The viable weights use subleading data, which is gauge-sensitive.** Under a residual
  near-identity gauge $h(x)=x+ax^2+\dots$, the quadratic germ coefficient shifts by $a\mu(\mu-1)\ne0$
  (DZT-checked). So $W^{(B)}$/$W^{(C)}$ depend on the convention; without a stamped convention and a
  covariance law, an audit measures the gauge, not the germ — exactly the contamination the B1 gate
  forbids. (Dyadic ledger already warns raw $p$-step, $F_1^p$, and normalized $p$-step coefficients
  are distinct absent a bridge.)

## Required data package (certified local $p=6$ germ near $P_1$)

1. **Coordinate / gauge declaration**
   - primitive coordinate; convention used (W_DSN / W_new / Birkhoff / Lie-gauge);
   - data layer: primitive, raw_pstep, F1^p, normalized_pstep, or observable_fit.
2. **Six-step local germ $G=T^6$**
   - Taylor jet through the first nontrivial nonlinear order, preferably through the order
     containing $Q_{\rm true}$ and $c_{21}$; exact algebraic coefficients where available.
3. **$Q_{\rm true}$**
   - exact definition; layer tag; gauge/convention dependence; transformation law under admissible
     residual gauges.
4. **$c_{21}$**
   - exact value / symbolic form; layer tag; status (THM/ALG/NUM); convention scope.
5. **NF coefficients**
   - certified Birkhoff/Lie-gauge NF coefficients needed for nonlinear recurrence weights, with
     explicit raw vs normalized vs fitted distinction.
6. **Validity and guards**
   - which quantities are theorem-grade, which gauge-fixed only, which diagnostic/finite-horizon.

## DZT-side tests (what DZT will do with the export)

- **$W^{(B)}$ (normalized $Q_{\rm true}$ contraction weight):** passes if gauge-stable or with an
  explicit covariance law, depends on certified nonlinear data, and yields a non-constant
  transform-level sequence.
- **$W^{(C)}$ (NF-coefficient recurrence weight):** passes if algebraically generated by the
  germ/NF recurrence (not hand-tabulated) and exposes a determinant / recurrence / pole-zero /
  valuation structure.
- **$W^{(A)}$:** already rejected ($\det(I-DG^m)=0$, $\mathrm{trace}=2$).

Audit order: $W^{(B)}$ first (closest to established invariants, easiest to make gauge-safe), then
$W^{(C)}$.
