OFN v0.12 adopted by the PI on 30 Oct 2026 and tagged `ofn-v0.12` (annotated, merge commit `2b2573f`; `dsn/RTG_ONTOLOGICAL_FOUNDATIONS.md` SHA-256 `55ff8ba85d4bb48b52266bdd9a44aa84efcd2cc19903d059266fa406a6bb76aa`; release record `records/ofn/OFN_v0_12_RELEASE_RECORD.md`). It supersedes v0.11 (`38a2f444…e9e4`). No OFN definition or OPEN status changed.
Class C now carries the exact identity $F_e-N(z_e)=-\tfrac{\kappa}{3}(N(z_e)+b_e)$, $b_e=\sum_{j\ne e}N(z_j)$: the dyad law holds on an edge iff its interface compensates its own output; under zero total interface the edge obeys $(1-\tfrac{\kappa}{3})N$.
OPEN-OFN-TRIAD-CLASS's physical-isolation obligation is split into I-comp (balanced invariant regime; class C meets it exactly), I-quiet (zero total interface; class C fails for $\kappa\ne0$) and I-remove (environment removed; needs a size-indexed law). None is selected; Standard C is unchanged and is not equivalent to $I_e\equiv0$. FMS wording that reads Standard C as physical isolation may wish to cite the frame; nothing is asked.
